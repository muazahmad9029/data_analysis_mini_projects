# PDF Table Topic Extractor

This Python script extracts tabular data from a PDF file containing topics and their corresponding subtopics. The data is processed and saved as a structured JSON file for future use.

## 🧠 Features

- Extracts table data from each page of a PDF.
- Parses topics and subtopics, preserving multiline subtopic entries.
- Saves extracted data to `table_metadata.json`.
- Avoids re-processing if the JSON file already exists.
